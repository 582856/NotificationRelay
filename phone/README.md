# RelayQuiet

手机跨设备通知免亮屏，当前版本 `0.1.3`，包名 `com.zephyr.relayquiet`。配合平板跨设备通知扩展 0.1.20 及以上使用，推荐同批发布的 0.1.25。

平板通过原有米联通道主动推送亮屏、息屏状态。手机仅对已开启向平板流转的应用判断：通知发送成功且平板状态为亮屏时，抑制对应通知的锁屏亮屏，最多暂缓200毫秒；超时沿用系统亮屏提醒。其他应用沿用系统亮屏流程。应用名单在米联启动时读取，之后随原厂订阅开关变化更新；系统界面重启时获取内存快照，每条通知只查内存名单。

声音、振动、通知内容、来电、闹钟以及主动唤醒沿用原厂行为。平板息屏、状态未知或发送失败时，手机继续原有提醒。首次使用及状态超过5秒时，在发送通知前补查屏幕状态；模块空闲时依靠屏幕事件推送。屏幕状态包只包含会话、顺序号和亮屏布尔值；手机内部只短时缓存通知标识与目标的摘要，诊断日志只记录固定状态。

发送成功采用米联的原厂回调，表示传输层成功；平板后续的应用过滤与界面展示仍由原厂流程处理。

## 使用

手机安装本模块，LSPosed / Vector 作用域勾选米联和系统界面；平板启用平板跨设备通知扩展 0.1.20 及以上，沿用原有作用域。重载手机米联通知进程和系统界面、平板米联通知进程后生效。

当前适配 Xiaomi `popsicle`，HyperOS `OS4.0.0.39.XPBCNXM`，米联 `18.2.2.0.2609141543`。现代 Xposed API 101，Android 14 及以上。

## 编译

JDK 17、Android SDK platform 37、Gradle 9.3.1。在 `phone/` 目录配置 SDK 后执行 `./gradlew :app:assembleRelease`，Windows 使用 `gradlew.bat :app:assembleRelease`。Release 开启 R8 和资源压缩。

仓库中的独立手机工程使用 Android 默认调试签名；发布的 APK 沿用维护者签名。签名不同的自行构建版本需卸载原应用后安装。第三方参考与许可说明见仓库根目录的 README。
